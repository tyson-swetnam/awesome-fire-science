# :fontawesome-solid-rocket: Getting Started

New to wildland fire science tools and resources? This page provides pathways to help you quickly find the right tools and tutorials for your specific goals.

## :material-target: "I want to..."

### Improve my daily efficiency with AI

Start using AI assistants to enhance your research workflow:

- **ChatGPT or Claude** - Writing assistance, code generation, data analysis → [AI Tools](ai-tools.md#generative-ai-assistants)
- **Microsoft Copilot** - Integrated into Office 365 for document creation → [AI Tools](ai-tools.md#microsoft-office-365-copilot)
- **GitHub Copilot** - AI pair programming for code development → [AI Tools](ai-tools.md#automation-scripting)
- **Perplexity** - AI-powered research with citations → [AI Tools](ai-tools.md#generative-ai-assistants)

### Analyze satellite imagery and remote sensing data

Work with Earth observation data for fire monitoring and analysis:

- **Google Earth Engine** - Cloud-based planetary-scale analysis with 50+ year satellite archive → [Computing](cyberinfrastructure.md#google-earth-engine)
- **GEEMap Python Package** - 360+ Jupyter notebooks for GEE tutorials → [Software](software.md#python)
- **Microsoft Planetary Computer** - Open Earth observation data and analysis tools → [Computing](cyberinfrastructure.md#microsoft-planetary-computer)
- **NASA FIRMS** - Real-time global fire detections from MODIS and VIIRS → [Data Sources](data.md#earth-observation-systems)
- **QGIS** - Free desktop GIS for satellite imagery analysis → [Software](software.md#gis)

### Run fire behavior models

Simulate fire spread and behavior:

- **FARSITE** - 2D fire growth simulation model → [Software](software.md#open-source-fire-behavior-models)
- **FlamMap** - Landscape-scale fire behavior mapping → [Software](software.md#open-source-fire-behavior-models)
- **BehavePlus** - Point-based fire behavior prediction → [Software](software.md#open-source-fire-behavior-models)
- **WFDSS** - Wildland Fire Decision Support System with integrated models → [Data Sources](data.md#incident-maps-historical-fire-atlases) | [Software](software.md#open-source-fire-behavior-models)

## :material-school: Learning Pathways

### For Students & Early Career Researchers

1. Start with **QGIS** for basic GIS skills → [Software](software.md#gis)
2. Learn **Google Earth Engine** for cloud-based analysis → [Computing](cyberinfrastructure.md#google-earth-engine)
3. Explore **Python or R** for data science → [Software](software.md#python) | [Software](software.md#r)
4. Join communities on **Slack/Discord** → [Community](community.md#slack-discord-communities)
5. Attend conferences like **AFE or IAWF** → [Community](community.md#conferences-events)
6. Explore **training courses and certifications** → [Training](training.md#getting-started-in-wildland-fire)

### For Fire Managers & Practitioners

1. Access **WFDSS** for decision support → [Software](software.md#open-source-fire-behavior-models)
2. Use **mobile apps** for field operations → [Mobile Apps](mobile-apps.md#fire-monitoring-alerts)
3. Monitor **GACC pages** for regional coordination → [Data Sources](data.md#incident-maps-historical-fire-atlases)
4. Subscribe to **InciWeb** for incident updates → [Data Sources](data.md#incident-maps-historical-fire-atlases)
5. Connect with **professional networks** → [Networks](networks.md#international-professional-associations)
6. Take **NWCG training courses** → [Training](training.md#federal-agency-training)

### For Remote Sensing Specialists

1. Master **Google Earth Engine** or **Microsoft Planetary Computer** → [Computing](cyberinfrastructure.md#google-earth-engine) | [Computing](cyberinfrastructure.md#microsoft-planetary-computer)
2. Learn **AI/ML tools** for image analysis → [AI Tools](ai-tools.md#ai-for-geospatial-remote-sensing)
3. Explore **WIFIRE** tools and datasets → [Data Sources](data.md#earth-observation-systems) | [Software](software.md#python)
4. Use **TorchGeo or Raster Vision** for deep learning → [AI Tools](ai-tools.md#foundation-models-for-earth-observation)
5. Contribute to **open-source projects** on GitHub → [Software](software.md#repositories-notebooks-and-short-courses)
6. Take **NASA ARSET remote sensing courses** → [Training](training.md#specialized-training)
