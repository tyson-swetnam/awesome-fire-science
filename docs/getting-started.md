# :fontawesome-solid-rocket: Getting Started

New to wildland fire science tools and resources? This page provides pathways to help you quickly find the right tools and tutorials for your specific goals.

## :material-target: "I want to..."

### Improve my daily efficiency with AI

Start using AI assistants to enhance your research workflow:

- **ChatGPT or Claude** - Writing assistance, code generation, data analysis ([AI Tools](ai-tools.md))
- **Microsoft Copilot** - Integrated into Office 365 for document creation ([AI Tools](ai-tools.md))
- **GitHub Copilot** - AI pair programming for code development ([AI Tools](ai-tools.md))
- **Perplexity** - AI-powered research with citations ([AI Tools](ai-tools.md))

### Analyze satellite imagery and remote sensing data

Work with Earth observation data for fire monitoring and analysis:

- **Google Earth Engine** - Cloud-based planetary-scale analysis with 50+ year satellite archive ([Computing](cyberinfrastructure.md))
- **GEEMap Python Package** - 360+ Jupyter notebooks for GEE tutorials ([Software](software.md))
- **Microsoft Planetary Computer** - Open Earth observation data and analysis tools ([Computing](cyberinfrastructure.md))
- **NASA FIRMS** - Real-time global fire detections from MODIS and VIIRS ([Data](data.md))
- **QGIS** - Free desktop GIS for satellite imagery analysis ([Software](software.md))

### Run fire behavior models

Simulate fire spread and behavior:

- **FARSITE** - 2D fire growth simulation model ([Software](software.md))
- **FlamMap** - Landscape-scale fire behavior mapping ([Software](software.md))
- **BehavePlus** - Point-based fire behavior prediction ([Software](software.md))
- **WFDSS** - Wildland Fire Decision Support System with integrated models ([Data](data.md), [Software](software.md))

### Monitor active fires in real-time

Track current fire incidents and get alerts:

- **Watch Duty** - Community-driven fire alerts and scanner audio ([Mobile Apps](mobile-apps.md))
- **InciWeb** - Official incident information ([Data](data.md))
- **NASA FIRMS** - Near real-time satellite fire detections ([Data](data.md))
- **NIFC Open Data** - Current fire perimeters and statistics ([Data](data.md))
- **GACC Pages** - Regional coordination center updates ([Data](data.md))

### Work with lidar and point cloud data

Process and analyze 3D point clouds:

- **PDAL** - Point cloud processing library ([Software](software.md))
- **CloudCompare** - 3D point cloud visualization and editing ([Software](software.md))
- **FUSION** - Lidar processing and analysis ([Software](software.md))
- **OpenTopography** - Access to lidar datasets ([Data](data.md))
- **USGS 3DEP** - National lidar coverage ([Data](data.md))

### Contribute to open science

Learn collaborative research workflows:

- **GitHub** - Version control and code sharing ([Software](software.md))
- **Jupyter Notebooks** - Reproducible computational narratives ([Software](software.md))
- **Zenodo** - Archive research data and code with DOIs ([Networks](networks.md))
- **FAIR Data Principles** - Make research findable, accessible, interoperable, reusable ([Data](data.md))

### Get weather and environmental data

Access meteorological and ecological datasets:

- **RAWS Stations** - Remote Automated Weather Stations ([Data](data.md))
- **NOAA Weather** - Forecasts and fire weather ([Data](data.md))
- **NEON** - National Ecological Observatory Network ([Data](data.md))
- **Ameriflux** - Eddy covariance flux tower data ([Data](data.md))

### Learn fire ecology and management

Educational resources and training:

- **Wildland Fire Management RD&A** - USFS Research and Development ([Software](software.md))
- **FRAMES** - Fire Research and Management Exchange System ([Software](software.md))
- **Fire Ecology Journal** - Open access research ([Data](data.md))
- **Online Courses** - MOOCs and webinars ([Training](training.md))

## :material-school: Learning Pathways

### For Students & Early Career Researchers

1. Start with **QGIS** for basic GIS skills ([Software](software.md))
2. Learn **Google Earth Engine** for cloud-based analysis ([Computing](cyberinfrastructure.md))
3. Explore **Python or R** for data science ([Software](software.md))
4. Join communities on **Slack/Discord** ([Community](community.md))
5. Attend conferences like **AFE or IAWF** ([Community](community.md))

### For Fire Managers & Practitioners

1. Access **WFDSS** for decision support ([Software](software.md))
2. Use **mobile apps** for field operations ([Mobile Apps](mobile-apps.md))
3. Monitor **GACC pages** for regional coordination ([Data](data.md))
4. Subscribe to **InciWeb** for incident updates ([Data](data.md))
5. Connect with **professional networks** ([Networks](networks.md))

### For Remote Sensing Specialists

1. Master **Google Earth Engine** or **Microsoft Planetary Computer** ([Computing](cyberinfrastructure.md))
2. Learn **AI/ML tools** for image analysis ([AI Tools](ai-tools.md))
3. Explore **WIFIRE** tools and datasets ([Data](data.md), [Software](software.md))
4. Use **TorchGeo or Raster Vision** for deep learning ([AI Tools](ai-tools.md))
5. Contribute to **open-source projects** on GitHub ([Software](software.md))
